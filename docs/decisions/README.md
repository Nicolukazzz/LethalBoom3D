# Decisiones técnicas (ADR)

Un archivo por decisión que costaría entender dentro de tres meses. Formato:

```markdown
# ADR-NNNN — título
Fecha · Estado: propuesta | aceptada | reemplazada por ADR-XXXX

## Problema
## Opciones consideradas
## Decisión
## Razón
## Consecuencias
```

No documentamos cada `if`. Documentamos lo que un desarrollador futuro (o nosotros mismos)
querría poder cambiar sin haber olvidado por qué se hizo así.
